\# JSON 数据比对工具（Json Compare Tool）需求规格说明书



\## 1. 项目背景



在接口开发、数据分析、系统联调过程中，经常需要比较两份大型 JSON 数据。



例如：



\* 接口升级前后返回数据是否一致

\* 不同环境（开发、测试、生产）接口返回是否一致

\* 第三方接口与本地数据是否一致

\* 股票、行情、交易数据同步结果验证

\* 数据迁移后的校验



目前通常依赖文本 Diff 工具（如 Beyond Compare、VS Code Compare），但对于包含数千甚至数万对象的 JSON 数组，这类工具难以快速定位业务数据是否一致，因此需要开发一套专门针对 JSON 数据结构的可视化比对工具。



\---



\# 2. 建设目标



开发一个无需安装、浏览器即可运行的 JSON 数据比对工具，实现：



\* 两份 JSON 数据可视化输入

\* 指定字段作为业务主键进行匹配

\* 快速找出相同、不同的数据

\* 高亮展示字段差异

\* 支持数万级 JSON 对象快速比较

\* 支持导出比较结果

\# 6. 功能需求



\## 6.1 JSON 输入



支持：



\* 粘贴 JSON

\* 上传 json 文件

\* 拖拽 json 文件



支持：



```

\[]

```



也支持：



```

{

&#x20;   "data":{

&#x20;       "list":\[]

&#x20;   }

}

```



\---



\## 6.2 JSONPath



支持指定真正的数据节点。



例如：



```

$.data.list

```



系统自动定位：



```

list

```



进行比较。



\---



\## 6.3 JSON 格式校验



点击开始比较前：



自动验证：



\* JSON是否合法

\* 是否为空

\* 是否数组



错误时提示：



```

A Json 格式错误



第128行



Unexpected token

```



\---



\## 6.4 自动识别字段



读取JSON以后：



自动扫描所有对象。



生成字段列表。



例如：



```

☑ code



☑ market



☑ price



☑ amount



☑ turnover



☑ updateTime



☑ name

```



用户无需手动输入。



支持搜索字段。



\---



\## 6.5 指定比较字段



支持：



单字段：



```

code

```



联合主键：



```

code



market



date

```



内部自动组合：



```

code\_market\_date

```



作为唯一Key。



\---



\## 6.6 比较模式



\### 模式一



完全一致



所有字段全部一致。



\---



\### 模式二（推荐）



主键一致



仅依据指定字段判断。



例如：



```

code



market



date

```



\---



\### 模式三



任意字段一致。



只要存在匹配即可。



\---



\## 6.7 字段差异



当：



主键一致



其它字段不同。



展示：



| 主键     | 字段    | A    | B    |

| ------ | ----- | ---- | ---- |

| 600519 | price | 1500 | 1505 |



支持高亮。
